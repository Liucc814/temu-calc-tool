# Cross-border E-commerce Unit Conversion Tool
A free online calculator for cross-border sellers, support common unit conversions for logistics & product listing.

## Features
- Weight conversion: Gram(g) ↔ Pound(lb)
- Size dimension conversion
- Volumetric weight calculator
- Currency conversion reference
- Fully responsive, works on PC / Mobile browsers
- No installation required, open and use directly

## Supported Platforms
Suitable for Temu, Amazon, Shopee, TikTok Shop, Shein and other cross-border e-commerce platforms.

## How to use
1. Visit the online tool: https://liucc814.github.io/temu-calc-tool/
2. Input your number
3. Get conversion result instantly

## About
This open-source lightweight web tool is built for cross-border merchants to simplify daily unit conversion work.
